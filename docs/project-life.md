# PROJECT LIFE · 朋聊产品设计与验收

基线为已验收的 `codex/penlia-p3-world` 提交 `bde5ee9`。重构分支为 `codex/penlia-ui-redesign`。保留 Expo SDK 58、React Native 0.88、Expo Router 及现有原生图标、选择器与媒体组件。

## 审计与设计决策

- **路由**。原应用有聊天、好友、玩乐、动态、我的五个一级路由。聊天分环信私聊和自有 HTTP 群聊。动态有服务端私密动态与本机空间。P1 约局、关系保护、共创和日记，P2 日程、旅行、收藏、地图、回忆、胶囊和生活状态，P3 接力和共同世界各有真实路由。保留五栏与 URL，玩乐默认展开「一起生活」。
- **主要问题**。首屏把多种动作并列为高亮按钮，群聊使用卡片替代气泡，私聊一排控件挤占输入空间，动态图片均固定高度，个人资料和平级设置区界线不清。浅色覆盖曾是 Web 的默认行为，Android 已有动态资源但外观入口只显示说明。先修通信层和通用组件，再按内容类型处理生活页面。
- **保留品牌**。品牌渐变端点 `#FF768D`、`#AEFFF8` 与过渡色 `#EAC8D5`、现有图标、玩乐 Glint、`OrbFace` 圆球、眼睛和眨眼逻辑均保留。仓库里找到的是组件及此前运行截图，未找到当时 Grok 原始参考图文件。欢迎区使用现有朋聊素材和静态宠物，避免增加循环动画。
- **权限与产品边界**。好友确认、群邀请同意、手机号查询开关、原作者独立授权、忙闲参考、共同世界和媒体撤权均继续使用原权限。受保护的分享只复制打开链接，并可把链接放进聊天草稿。保留既有演示隔离；短信、环信、RTC、厂商服务继续按实际配置显示。后台、数据库和迁移不在本轮改造范围。

## 设计系统

`src/palette.json` 和 `src/theme.ts` 定义原生浅暗色、Web 语义色、系统字体层级、4/8 间距、8–24 圆角、实色表面层级和动效时间。外观可跟随系统，也可选浅色或深色。偏好在本机保存。导航和片层读取系统减少动态效果偏好，现有宠物动画保留前后台暂停机制。

`src/components/ui.tsx` 负责导航标题、按钮、头像、列表行、开关分组、选项、片层、加载、空内容和错误状态。通用点击区域以 iOS 44pt、Android 48dp 为目标。主正文 16/24，导航标题 26/34，区块标题 19/26，辅助说明 14/21。从账号进入会话沿用五栏与页面路由，图片查看使用独立暗底阅读层。新增的对比度测试校验正文、说明、按钮和消息气泡的浅暗色组合。

## 页面改造清单

| 页面 | 改造内容 |
| --- | --- |
| 消息首页 | 搜索、圆形头像、会话摘要与时间构成清晰行式布局。使用既有 SDK 置顶状态和安静送达标识，真实连接失败保留重试入口。 |
| 私聊与群聊 | 共用输入栏、连续消息分组、时间轴、头像显示和消息操作片层。图片仍与附件按钮相邻，长按可看文本及时间并进入已有举报。安静送达和只是分享在发送选项内独立操作。 |
| 登录、注册与滑块演示 | 共用品牌条、欢迎画面、圆球宠物和输入层级。真实账号密码、头像选择、验证码触发顺序与独立演示行为沿用现有实现。 |
| 动态、发布、图片查看 | 内容优先的无独立卡框 feed，响应式单图和双列，视频点击播放，原范围与共创入口保留。发布可只选图片，明确显示可见范围。 |
| 好友、好友资料、我的 | 搜索、好友申请与会话仍是两条清晰路径；资料头像、签名及状态分层，关系操作收进片层；我的采用分组设置与可持久保存的外观偏好。 |
| 隐私、设置及其他现有功能 | 共用设置分组、44/48pt 控件和语义状态。保留添加、查询、邀请、通知、举报、审核、设备等已有路径和设置条件。 |
| 玩乐与共同生活 | 「一起生活」提前，按见面、记录、收藏分组。小游戏、去处和已有邀请功能仍可从同级分类进入。 |
| 约局、心愿共振、共享日程 | 活动主卡突出时间地点和确认状态；心愿、约局、共同记录和邀请统一频道标记；按日周月浏览，保留成员区分及空闲参考原义。 |
| 旅行、愿望地图、收藏 | 旅行展示获授权的首张行程照片、目的地、日期和时间线。地图只绘制真的经纬度，地点名可以单独收藏。 |
| 共创动态、共同日记、回忆、胶囊 | 日期、作者和正文优先呈现，复用媒体查看器。既有作者授权、回忆来源与胶囊开启约束继续执行。 |
| 瞬间共鸣、共同世界 | 作者署名和按时间追加的内容采用时间线。世界有三套亮暗布景、真实成员入口及现有轻量宠物，保留独立授权与原记录跳转。 |

### 既有路由与覆盖范围

| 路由 | 本轮覆盖 |
| --- | --- |
| `/`、`/friends`、`/play`、`/moments`、`/me` | 调整页面或共享内容结构，并统一五栏外观。 |
| `/auth`、`/chat/[id]`、`/group/[id]`、`/person/[id]`、`/privacy`、`/private-moment` | 调整核心区块、输入、反馈和片层。 |
| `/social`、`/gathering/[id]`、`/collection/[id]`、`/journal-entry/[id]` | 调整共同入口、详情首屏或内容时间线。 |
| `/life`、`/life/calendar`、`/life/items`、`/life/memories`、`/life/moment/[id]`、`/life/project/[id]` 的旅行详情 | 调整频道、日历、收藏与地图、回忆、动态及旅行内容布局。 |
| `/world`、`/world/[id]` | 调整入口、空间场景、纪念物及瞬间接力排版。 |
| `/groups`、`/contributions`、`/boundary`、`/review/[id]`、`/life/projects`、`/life/capsule-drafts`、`/life/status`、`/life/reminders`、`/world/own`、`/space/*`、`/playground/*`、`/pet/[id]` | 使用新版公共主题和组件。子页面原有业务表单与内容结构沿用，并未逐页重排或验收。 |
