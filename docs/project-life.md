# PROJECT LIFE · 朋聊产品设计与验收

基线为已验收的 `codex/penlia-p3-world` 提交 `bde5ee9`。重构分支为 `codex/penlia-ui-redesign`。保留 Expo SDK 58、React Native 0.88、Expo Router 及现有原生图标、选择器与媒体组件。

## 审计与设计决策

- **路由**。原应用有聊天、好友、玩乐、动态、我的五个一级路由。聊天分环信私聊和自有 HTTP 群聊。动态有服务端私密动态与本机空间。P1 约局、关系保护、共创和日记，P2 日程、旅行、收藏、地图、回忆、胶囊和生活状态，P3 接力和共同世界各有真实路由。保留五栏与 URL，玩乐默认展开「一起生活」。
- **主要问题**。首屏把多种动作并列为高亮按钮，群聊使用卡片替代气泡，私聊一排控件挤占输入空间，动态图片均固定高度，个人资料和平级设置区界线不清。浅色覆盖曾是 Web 的默认行为，Android 已有动态资源但外观入口只显示说明。先修通信层和通用组件，再按内容类型处理生活页面。
- **保留品牌**。品牌渐变端点 `#FF768D`、`#AEFFF8` 与过渡色 `#EAC8D5`、现有图标、玩乐 Glint、`OrbFace` 圆球、眼睛和眨眼逻辑均保留。仓库里找到的是组件及此前运行截图，未找到当时 Grok 原始参考图文件。欢迎区使用现有朋聊素材和静态宠物，避免增加循环动画。
- **权限与产品边界**。好友确认、群邀请同意、手机号查询开关、原作者独立授权、忙闲参考、共同世界和媒体撤权均继续使用原权限。受保护的分享只复制打开链接，并可把链接放进聊天草稿。保留既有演示隔离；短信、环信、RTC、厂商服务继续按实际配置显示。后台、数据库和迁移不在本轮改造范围。

## 设计系统

`src/palette.json` 和 `src/theme.ts` 定义原生浅暗色、Web 语义色、系统字体层级、4/8 间距、8–24 圆角、实色表面层级和动效时间。外观可跟随系统，也可选浅色或深色。偏好在本机保存。导航和片层读取系统减少动态效果偏好，现有宠物动画保留前后台暂停机制。

`src/components/ui.tsx` 负责导航标题、按钮、头像、列表行、开关分组、选项、片层、加载、空内容和错误状态。通用点击区域以 iOS 44pt、Android 48dp 为目标。主正文 16/24，导航标题 26/34，区块标题 19/26，辅助说明 14/21。从账号进入会话沿用五栏与页面路由，图片查看使用独立暗底阅读层。新增的对比度测试校验正文、说明、按钮和消息气泡的浅暗色组合。

### 页面盘点与采用规则

| 页面 | 走查与本轮决定 |
| --- | --- |
| 聊天、好友 | 消息摘要／时间和通讯录字母分段已形成清晰的扫描路径。保留现有密度与互动。 |
| 玩乐 | 「线下去处」、城市、收藏以及结果之间缺少清晰层级。用标题与细分隔线组织浏览顺序，首条让照片建立场景，其余用定高方形缩略图和可换行的文字行。 |
| 去处详情 | 封面、来源、适用场合和分享动作各自分散。建立全页唯一大标题，来源披露贴近地点信息，分享留在安全区内的底部操作栏。 |
| 动态、发布动态 | 信息流已使用明确的作者、时间和媒体结构。试点只调整发布与编辑使用的表单，正文与媒体共用画布，地点与可见范围同组但各自独立可操作。 |
| 我的、隐私 | 个人资料及设置已按任务分组。留作后续设置类试点，沿用当前页面。 |

采用 **Oura** 的摄影与留白、弱化阴影和“标题表达气质，正文承载事实”的层级。采用 **Airbnb** 参考中的照片优先、地点信息节奏与详情操作常驻。研究过 **Apple** 的节制材质与 **Wise** 的表单层级，延续已有朋聊玻璃和系统汉字字体。字体、素材、配色和图标沿用朋聊资产。

- 字体按 32/39 详情标题、24/32 区块导标题、18/26 小标题、16/26 长文和 14/21 说明建立层级。正文和输入采用常规字重。所有字号继续由现有字号设置缩放，文字可自然换行。
- 区块、照片、输入和列表使用现有 8／12／16／20／24 dp 间距。轮廓用细分隔或表面色，保留相片的比例。地点标题及照片、来源标签、正文共享同一阅读轴线。
- 强渐变用于发布和本地示例的聚会提议，次级操作采用低对比度材质或图标。沿用系统减少动态效果设置及既有媒体拖动反馈。
- 用现有组件区分加载、无推荐、不可用与失败信息。保留草稿读取重试。控件沿用 44/48 dp 的最小热区，小屏和大字体允许筛选项与底部操作换行。
- 试点样式位于 `src/features/design/pilot.ts`。共享卡片和按钮通过参数启用试点外观。推广时按内容类型逐页启用，逐页检查大字体、深色和原有任务，再决定是否将稳定规则纳入全局。

### 试点验证

使用 React Native Web 的演示构建在 Chromium 采集三组 390 × 844 同状态对照，在 320 像素宽度检查超大字号、深色和输入焦点，并用缩短视口检查滚动。验证了城市和类别筛选、空列表、收藏保存失败及恢复、多对象分享、混合媒体拖动、草稿重载、预览和发布。复查好友申请排列、聊天附件及卡片、个人空间顶部三处图标的透明背景与至少 44 像素热区。TypeScript、49 项测试、Web 导出及 Android JavaScript bundle 导出通过。设备上的原生键盘、系统缩放、相册以及 Release APK 运行仍需真机验证。
