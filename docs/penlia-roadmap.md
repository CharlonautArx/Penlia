# 朋聊分阶段开发进度

基线为远端 `codex/penlia-media-and-calls` 的 `905ca84`。P0 使用 `codex/penlia-p0-privacy`。每阶段交付并停在人工验收节点。功能编号 24 跳过。

现有 App 使用 Expo SDK 58、React Native 0.88、Expo Router。五个 Tab 顺序符合需求。FC Web 使用 Node.js 原生 HTTP 与 PostgreSQL 17，通过 `pg` 执行参数化 SQL，无 ORM。密码认证及现有好友申请已接入数据库。手机号挑战与限额已有服务端实现，真实验证码及短信适配器仍需配置。环信用于一对一通信和附件历史。设备头像、空间动态及小宠物保存在本机。通话为独立演示及 RTC 接口。产品已具备好友列表、文字、图片和位置私聊界面。服务器没有群聊、私密动态和通知策略。
