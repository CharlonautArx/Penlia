# Penlia 0.1.10 验收记录

客户端改动基于 `e3bebe7`，应用源码提交为 `a5d61c5`。ARM64 构建提交 `1ed100f` 只增加了独立 ARM64 构建入口与 Gradle 插件解析预检。两个构建使用相同的 TypeScript 源码和 Expo 依赖锁文件。

| 项目 | 实现与验证 |
| --- | --- |
| 收藏与好友推荐 | 两条胶囊分段支持横滑和点击。收藏分类为美食、景点、休闲和聊天记录。旧去处读取相同的账号本机收藏键，出现在景点。旧电影、音乐和其他收藏归入休闲，原类别和记录保留。Web 验证横滑、旧收藏读取及小屏超大字号。 |
| 聊天收藏 | 紧凑摘要显示发送人、原消息时间和图片缩略图。详情显示头像、原内容和收藏时间。新记录存储稳定发送人标识，历史记录优先匹配唯一好友名称，无法确认时保留原标签。Web 实测修改备注后列表和详情同时更新，并跑通聊天图片收藏和原图展示。 |
| 个人资料与主页 | 二维码图标向右 4 dp、21 dp 缩至 19 dp，触控区沿用现有尺寸。个人资料去除恢复默认头像按钮并更新状态名称。本人主页由封面点击进入编辑，图库选图后复用全屏手势裁剪并按实测封面宽高比保存。 |
| 约局 | 邀请对象沿用好友列表和备注，增加头像。小日历可选年月日，时间滚轮按本地时区保存，24:00 表示次日零点。服务端邀请与通知在同一事务保存，参与者的私聊查询按当前好友和成员权限读取，聊天卡片打开原约局。客户端在会话打开或定期刷新时加载。 |
| 时间胶囊 | 服务端拒绝创建者或成员对已加入及待接受对象的移除请求。创建者和已加入成员都可自行退出。创建者离开未封存的胶囊后会失去访问和封存权限，退出前有明确提示。投稿仍可由作者自行撤回。 |

## 自动化与范围

TypeScript、差异与语法检查通过。基础和安全测试 51/51。隔离 PostgreSQL 中 Together 5/5、P2 14/14、聊天记录 5/5、P1 8/8 和 P3 8/8。HTTP 测试覆盖邀请重试、发送方和接收方读到同一卡片、被移除及非受邀者无权读卡片、重新邀请产生新卡片，以及收藏原图权限和时光胶囊自愿退出。

同一账号、时间、390 × 844 视口和字体设置的 Web 对照中，好友页、动态页和原私聊消息的文字、图片来源和按钮位置一致。截图均使用运行中的演示 App 和演示数据。APK 使用预览包名 `app.penlia.mobile.preview`。隔离 API 双账号测试与单机演示分别验收，生产服务未部署，实体设备未参与本次验证。

## Android Release

ARM64 使用完整 Expo prebuild、Gradle Release 和 R8 构建。对 GitHub 直链下载回来的 APK 校验了 SHA-256、归档、签名、ARM64 架构和 16 KB ZIP 对齐。包名及签名证书与 0.1.9 预览版一致，versionCode 为 22。

Android 15 x86_64 模拟器通过冷启动、旧去处收藏读取、聊天收藏与详情、从系统图库选择照片后的全屏裁剪、保存后重新打开主页、胶囊自行退出。裁剪保存与重新打开后的主页封面区域逐像素一致。首轮约局脚本点到了字段标题，复测对同一份 APK 选择了可点击控件，跑通日历、时间滚轮、好友头像和选择、发送、聊天卡片及打开详情。
