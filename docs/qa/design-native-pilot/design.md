### 其他主要表面的源码复查

- 好友目录已有搜索、独立申请入口、按字母定位、关系分组与群聊，检索效率依赖稳定的行首头像和行尾索引。改变所有列表的默认密度会同时改变这些位置。
- 玩乐先放「一起」，再呈现线下去处、城市、分类和首图推荐。推荐大量依赖真实图片比例，世界和邀约的试点控件应当局部生效。
- 「我的」通过个人资料、隐私与安全、我的生活、偏好设置组织入口。普通描边按钮、渐变按钮和不可点击说明在此前版本存在视觉近似的情况。设置页尤其需要保持可点击行和说明文的区别。
- 五栏图标、字号偏好、安全区计算、Sheet、搜索框、滚动和键盘处理跨页共用。旧版走查图中的「新的朋友」「想去的地方」已与当前源码不同；诊断以源码和本轮运行图为准。登录、好友确认、举报、安静时间等高影响流程沿用既有 UI 和权限设计。

- 个人资料以「朋聊号／昵称／个性签名」三个编辑行读写账号，地区和状态在补充资料中单列；朋聊号有时间与可用性反馈。设置类页面的“保存中”、禁用与错误提示承担真实状态，不能借材质调整抹去差异。
- 发布动态的三列媒体网格、拖动排序和无障碍替代动作、可见范围、草稿恢复属于一条完整任务链。表单超限才提示、不隐藏已经选好的媒体。这些表面的内容密度与约局详情不同。
- 复查历史 Android Release 报告的日期小历、小时与分钟双滚轮、输入时的系统键盘避让。另检查仓库历史好友／玩乐／我的图作为视觉沿革。以上辅助材料不计为本轮针对这些外部页面的原生复测。[日期与滚轮，第 3 页](../favorites-gathering-profile/screens.pdf) · [活动创建和键盘，第 2 页](../together/android-screens.pdf)

## 四稿的艺术方向与取舍

| 方案 | 五页设计共用的视觉主语 | 可观察的收益 | 需要防守的代价 |
| --- | --- | --- | --- |
| A 温润生活主义 | 先认出熟人的头像，再见到最新一句话。照片、场景和真正的见面地点形成生活感，亲疏留白体现节奏。 | 人际关系成为视觉线索。适合从聊天自然进入动态和共同生活。 | 第一屏若让过多人像、大片留白占位，会提高找到低频联系人的成本。 |
| B 现代原生极简 | 从可执行动作和真实状态出发。紧凑的共同对齐轴、少数清楚的标记、稳定的行高让列表容易快速扫描。 | 对常用联系人查询、单手导航和大字体容错有优势；最容易外推到已有工具型页面。 | 细分隔、灰标签若过密，容易把生活社交推向事务列表；需要保留图像和人物重量。 |
| C Apple 风格 | 用较大导航标题、收拢的同组操作和清晰的前后景表达位置。视觉深度集中于功能层，长内容有稳定底色。 | 从世界到邀约都能建立空间连续性，照片与状态相邻。 | 玻璃上小字的对比、Android 不同系统合成和帧耗，需要原生复查。图标与字体用已有授权资源。 |
| D Claude 风格 | 先读一句真实的话。阅读标题与署名、工具文字分工，分享正文有舒适行距和边距，暖色只标示少数可操作内容。 | 长中文状态、活动说明和纪念物更容易慢读，四方案中最适合检验中文排版。 | 中文系统衬线存在设备回退；长标题占据高度，多人消息场景需要控制层次。 |

第一阶段的专业倾向为 **A**。朋聊的差异化来自与熟人之间可持续的生活联系，这条主线能同时解释消息、分享和约局。可借用 B 的搜索效率和稳定读序、C 的控件分层、D 的长文节奏。候选方向不应通过堆叠四套材质推广；确认前保留四选一及原版。上述收益与代价是设计判断。用户偏好、长期留存及真实手机热耗需要独立证据。

## 手机视口视觉检查

第一轮 Expo Web 辅助检查使用 390 × 844 的固定测试内容，逐一查看四组五页。A 的首个联系人整行绿色容易引出“已选”的误解；B 的动态在没有封面照片时出现大块预留区；C 的会话尾部同时呈现时间、未读与箭头，受窄宽限制；D 的引句优先有辨识度，联系人署名却偏小。另有一处跨四稿问题：邀约页的「活动留言」保留独立灰按钮，破坏与同组私密选择的关系。已将具体页面、位置和修订方向交给对应工程师。

对试点语义色的浅、深两套实色进行 sRGB 相对亮度计算。正文和辅助字在背景上的最低对比分别为 13.18:1 和 5.73:1；强调字在自身浅色块上的最低值为 4.74:1，出现在 D 浅色。计算覆盖四种方案的 40 个组合，摄影、雾化、玻璃与系统字体缩放仍需看实际运行结果。
