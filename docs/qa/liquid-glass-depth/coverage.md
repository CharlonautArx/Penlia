## 组件候选清单

统计单位为可复用控件或有明确职责的独立表面。列表中重复出现的同一组件只计一次。路由矩阵与设备材料独立核验。锁定项以及系统或内容表面单独记录，不计入适用材质改造分母。

| 适用类型 | 主要原有实现 | 材质安排 |
| --- | --- | --- |
| 标题栏 | `TopBar`、一起顶部 | 按现有是否覆盖内容使用边缘或实时采样 |
| 返回／更多／悬浮操作 | `IconButton` | 保留点击区域和无底形状约束；有底控件明显弧面 |
| 消息与好友搜索 | `SearchField` | 中等、焦点边界 |
| 普通表单输入 | `Field` | 中等边缘，不遮盖编辑光标 |
| 账号输入 | `LegacyAuth` | 中等、保留注册状态 |
| 发送输入条 | `MessageComposer` | 中等／强；壁纸存在时局部实时采样 |
| 发送按钮 | `MessageComposer` | 强／中；禁用保留状态区分 |
| 聊天气泡 | `ChatBubble` | 轻边缘，无逐气泡取样 |

需单独注明的范围包括底栏及其高光／沙盒、已认可的原生药丸开关、独立滑块、现有收藏和好友滑动控件、没有圆底的空间工具、应用外 Android 窗口、媒体内容与字形。管理员、有效分享票据、服务端有权限状态和真实通话不使用生产账号做验证。

源码登记为 59／59 个页面路由和 6／6 个共享布局。24 类候选中，21 类接入或调整材质，3 类保留现有玻璃（通用分段、媒体查看边缘、通话操作）。该统计以表中控件类型为单位，不能替代各页面及状态的运行结果。主消息搜索框的上一版光学边缘和颜色在试点前后对照后恢复；同一 SearchField 的普通和中性样式采用新材料。随不同数据分支渲染的自定义输入、内容容器、系统控件有各自例外，不能将 21 类等同于每个独立调用点。
