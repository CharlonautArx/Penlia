## 已实施的代码控制

- [长期规范](../AGENTS.md) 适用于后续开发、构建、发布和应急处理。Expo 只接受审核过的三个公开变量。EAS 开发、预览与生产各用独立环境，离线演示走开发环境。归档扫描覆盖嵌套 APK/AAB/ZIP，旧的预构建服务端 ZIP 已移出当前分支的版本控制。
- 外部 PR 检查采用 `pull_request` 和只读权限，Actions 固定到完整提交，checkout 不保留令牌。Android 诊断只上传通过扫描的 APK、离线截图和固定类别摘要，原始系统日志和 UI 转储留在 runner。
- 生产启动验证环境、数据库名、TLS 以及运行角色。应用进程拒绝拥有建库、业务表所有权、公共模式 DDL 或广泛读写角色的账号。服务端 ZIP 以允许的文件类型构建，CA 输入只能包含公开证书。
- 环信鉴权由后端根据朋聊会话绑定账号签发，User Token 最长 15 分钟。用户、好友关系和全局限流在付费或高风险调用之前执行。发送前回调验证签名与时间戳，并绑定首次载荷；改写载荷的重放被拒绝，原样重试仍校验实时好友关系。迁移 `019_provider_callback_replay.sql` 需先于新版服务部署。
- 短信保留服务端 CAPTCHA、一次性证明、手机与设备频控、原子费用预留和停发开关。受保护的用量接口新增日额度与供应商结果异常指标。短信、对象存储、点评和携程仍需按实际供应商配置，仓库内没有为这些服务开放通用转发接口。

## 验证结果

- TypeScript 与 48 个应用及安全测试通过。45 个隔离 PostgreSQL 和 HTTP 集成用例通过，另使用临时 TLS 证书验证最小权限角色可以启动，DDL、全库读和表所有权分别导致启动检查拒绝。
- 新版 Expo Android 导出和重新生成的服务端 ZIP 通过凭证扫描，在 Android 导出中未发现注入的合成服务端凭证。嵌套归档中的合成私钥会使扫描失败，混有私钥的 CA 文件会被打包脚本拒绝。旧服务端 ZIP 的遗漏模块依赖已修正，重建包解压后可加载 HTTP 入口。
- 这次没有部署生产服务、使用真实供应商计费接口或访问生产数据库。真实设备上的第三方联调和云端控制台状态另行验证。
