# 朋聊 P3 开发与验收

P3 开发分支为 `codex/penlia-p3-world`，起点为已验收的 P2 提交 `f55fcc9`。范围为功能 23 和 25。第 24 项「玩乐号」继续暂缓。最终配置按 [全阶段联调与上线清单](../FINAL_INTEGRATION_CHECKLIST.md) 等待授权。

| 编号 | 本次交付 | 权限 |
| --- | --- | --- |
| 23 · 瞬间共鸣 | 从动态或「一起生活」进入。新建有发生日期的接力、邀请好友、接受或谢绝、追加文字和最多 6 个图片或短视频附件。可关联共创动态、共同日记和共同世界，从原记录返回接力，或显式保存为 P2 共同回忆。 | 发起者只管理邀请。投稿与连结初始仅作者可见，作者逐位选择已加入的成员并确认。新成员不会继承旧授权，成员名单变化使旧确认失效。作者可编辑、改可见范围或撤回，退出后仍可撤回。撤回清除正文、媒体和授权，并保留最小重试标识以防旧请求复活内容。 |
| 25 · 共同世界 | 经邀请加入的成员共同选择三种 2D 布景、命名并互动渐变小宠物，在网格中摆放或移动自己的装饰。共同相册、日志、已完成旅行、已开启胶囊、回忆及接力可成为纪念物。 | 纪念物保留原记录链接。作者和查看者都要能打开源记录，并且查看者须获纪念物作者明确授权。可见范围缩小、作者撤回、退出、拉黑或源记录删除后，重新请求不返回相应内容。 |

连结只引用原始资源，不复制媒体或替原作者发布内容。共创动态、日志和相册继续使用 P1 原有的逐作者、逐媒体鉴权。接力保存成回忆后默认为仅本人，显式分享还要满足原接力的成员权限。宠物互动同步最近一次打招呼的时间，沿用单个轻量组件、系统减少动画设置和前后台暂停机制。互动与装饰没有付费、打卡、衰减或连续奖励。接力按页加载，默认只预览少数附件，短视频由用户主动播放。

## 主要代码和数据库

- [P3 服务端](../server/p3/routes.mjs) 新增 `/v1/p3/spaces`、邀请与成员操作、分页记录、场景和宠物状态、原记录选择、接力反向连结、本人撤回入口。复用应用内邀请事件、关系、处置和私有媒体服务。
- [作者授权与连结](../server/p3/records.mjs) 通过成员与作者独立确认保存文本、媒体、连结和装饰。修改使用记录版本，涉及分享时同时核对成员名单版本。普通的 `GET`、`HEAD` 和视频 Range 共用授权谓词。
- [P3 页面](../src/app/world/index.tsx) 和 [2D 场景](../src/features/world/scene.tsx) 通过既有导航、媒体和主题组件接入。正式功能入口走真实 API。演示构建通过路由保护隔离 P3。
- [008 SQL](../server/migrations/008_shared_world_p3.sql) 新建 `p3_spaces`、`p3_members`、`p3_records`、`p3_record_viewers`、`p3_media`，扩展既有回忆源约束以接收 `relay`。既有迁移脚本逐字节核对。[008 DMS 下载](../server/deploy/penlia-p3-dms.sql) 在 007 后用迁移账号执行，业务角色只取得所需数据操作权限。
