# 原生共同世界的验收依据

共同宠物会持续活动。Android 自带的 UI Automator 有时会在等待页面静止时超时。验收优先使用可见的原生视图 ID、“晚风小院”和另一项房间内容；读不到视图树时，会检查实际前台应用、设备配置及两次新截取的画面。该过程只在隔离模拟器执行。

`world-anchors.json` 保存两处不含宠物的灰度边缘特征，分别取自房间标题和含“暖灯／纪念物”的摆放格。坐标为归一化后的 200 × 444 画布坐标。参考图来自 R3 的五个原生浅色及深色界面，另保留 R1 的 A／C 旧版构图。每个区域在 400 像素宽灰度边缘图上裁取，缩为 28 × 12，再以 zlib 和 base64 保存。比对仅使用布局和笔画，不依赖头像颜色、动画的位置或系统状态栏。

两处必须在同一垂直位移下同时吻合。每项相关系数至少为 0.61，均值至少为 0.73，且目标方案的均值领先其余四案至少 0.10。五个方案和不通过条件均直接用于真实测试。固定阈值在 R2 独立运行、不同系统栏位置的 R3 复测、以及相同设备的 40 张非世界页面上检查过。每张交付图都在核验之后重新从模拟器截取。
