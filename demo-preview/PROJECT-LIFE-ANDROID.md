# 朋聊 PROJECT LIFE · Android 离线预览

从 `codex/penlia-project-life-demo` 的 `e99f649` 构建，基于最新美化提交 `012bf79`，包含已验收的 P0–P3 页面代码。

## 安装

1. 用安卓手机浏览器登录有 Penlia 私有仓库权限的 GitHub 账号。
2. 点 [APK 文件](penlia-project-life-arm64.apk) 后，选择 Download raw file 下载 `penlia-project-life-arm64.apk`，下载后点开文件。
3. 若 Android 提示授权安装来源，允许浏览器或文件管理器安装，完成后打开桌面的「朋聊演示」。
4. 点「直接进入演示」。演示账号、聊天、发布内容和常用设置留在本机。

## 可以体验

聊天、群邀请和本机群聊、好友资料、图库换头像、照片预览、动态发布与可见范围、个人空间、外观切换，以及「玩乐 → 一起生活」里的心愿、约局、日记、日程、旅行、收藏、地图收藏、回忆、胶囊、生活状态、瞬间接力和共同世界。共同宠物可在单聊或好友资料中打开。所在页面标注「演示」。

账号和素材均为演示。真实短信、跨设备同步和群视频等待正式服务接入；单聊通话可体验本机模拟界面。扫码交互、胶囊录音留存和完整的多成员授权链路不在本次离线模拟的验证范围。自用预览包使用与旧版一致的测试签名。
