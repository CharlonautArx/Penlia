# 朋聊 v7 动态栏目与 Android 键盘验收

基于已验收的 v6 提交 `6c44f7b`。本轮修复分支为 `codex/penlia-pane-ime-fix`。

## 录屏分析与修复

- **动态栏目。** v6 的 `Feed.tsx` 把日志和相册推入 `/space/[id]`，旧空间页再把「动态」替换为个人时间线，与第一段录屏一致。现在同一个 `FlatList` 只保留一份 `SpaceHeader`。切换本地 `pane` 时替换卡片下方内容，保留相册筛选，也不会因栏目切换重新请求好友动态。日志和相册复用原本机数据和权限检查。打开实际日志、相册或预览才进入内容详情。
- **个人时间线。** 常规入口仍为动态首页的本人头像。旧 `mine`、`author` 和 `local` 深层链接仍然有效；旧本人的日志／相册地址直接打开统一页面的相应栏目。其他人的本机演示空间、好友视角预览及自己的历史归档仍保留权限约束。保留原排序和置顶操作。
- **聊天键盘。** 第二段录屏中系统输入法已出现，但输入栏仍在窗口底部。v6 的清单已是 `adjustResize`，聊天和群聊在 Android 完全依赖系统缩窗。首轮 Release 模拟器在 IME 上缘 y=1432px 时仍测到输入框下沿 y=1548px。最终修复用 Expo 正式配置固定 `resize`，Android 的 `ChatViewport` 通过仓库内 Expo 模块取得系统 IME 边界和聊天视口下沿，两者统一使用屏幕坐标；仅补偿真正重叠的部分。系统已完全缩窗时补偿为零。使用系统 Insets 动画回调，iOS 保留原避让，没有新增第三方依赖。华为设备的窗口 Insets 原因尚无设备日志可核实。
- **输入与消息。** 多行输入使用原组件，最大高度 124dp，达到上限后在文本框内滚动。发送时输入框保持可编辑，成功后只清理本次提交的草稿，已有发送锁和幂等逻辑保留。图片、表情和附件打开前收起系统键盘。聊天仍用原倒序列表，没有加入强制滚动。

## 静态与业务检查

- TypeScript、Expo SDK 58 依赖、Expo Doctor 20/20 通过。Expo introspection 和打包后的二进制清单均确认 `adjustResize`。
- P0–P3 和动态／状态共 40 项测试通过，使用隔离 PostgreSQL 17，未改动应用数据库结构或生产连接。
- 实际 Web 演示通过三轮栏目切换的路由栈和头像坐标断言、写日志、新建和浏览相册、相册筛选返回保持、个人时间线置顶及旧链接兼容。用实际 v6 界面写入日志、创建相册、选取封面后切到 v7，确认相同本机文档逐项一致，历史动态仍可查看。

## Android 15 实际运行

通过 Android 15 Pixel 6 模拟器安装最终 Release 并使用系统 LatinIME 键盘。两次往返「动态／日志／相册」时，头像边界坐标一致且没有返回箭头。打开具体相册和本人时间线后，系统返回回到原栏目。导航共用同一个列表，保留相册筛选。内容变短时由列表调整可滚动范围。

| 场景 | Android UI 实测坐标（像素） |
| --- | --- |
| 首轮候选复现遮挡 | 键盘上沿 1432，输入框下沿 1548 |
| 最终包单行 | 输入框 y=1292–1423，发送键下沿 1421，键盘上沿 1432 |
| 三行 | 输入框 y=1167–1423，键盘上沿不变 |
| 达到多行上限 | 输入框 y=1087–1423，实测高度 336px，约 124dp |
| 三次收起和重新打开 | 每次输入框下沿都回到 1423，收起后都还原到初始位置，草稿继续可编辑 |

英文与换行由 Android 按键输入。混合中文、英文和 Emoji 的文本在真实键盘仍打开时通过 Android 输入框的无障碍接口注入并发送。发送后输入框清空，消息泡出现在聊天中。测试器单独安装在模拟器，未打进交付包。早先脚本直接匹配被 XML 转义的 Emoji，以及偶发获取不到活动输入框焦点。已更正 XML 解析，并将设备测试分为输入和工具用例。 [最终包键盘与栏目证据](https://github.com/CharlonautArx/Penlia/actions/runs/44940889398)

## 真机验收

用覆盖安装保留已有演示数据。打开「动态」，往返「日志」「相册」数次，确认标题、封面和头像不跳转、个人时间线由本人头像打开。然后在原来出现遮挡的华为输入法上测试中文候选、连续三行与 Emoji，发送或按系统返回键后再次输入，确认输入栏始终可见、草稿没有丢失。若使用卓易通，也用同一份 ARM64 包复测宿主窗口。当前无华为实体设备，模拟器的标准 Android IME 不能验证华为的候选词和卓易通动画。
